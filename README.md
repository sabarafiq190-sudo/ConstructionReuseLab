# Lab 07 – Construction for Reuse: Interfaces, Generics, and Contracts

University of Engineering and Technology, Abbottabad Campus
Course: Software Construction | Instructor: Engr. Rizwan Shah

## Tasks
- **Task 1:** Black-box reuse using PaymentMethod interface and EcommerceCart (composition).
- **Task 2:** Generic class DataBox<T> showing compile-time type safety.
- **Task 3:** LSP violation (Rectangle/Square) and its fix using Shape interface.
- **Task 4:** Student sorting using Comparable (rollNo) and Comparator (CGPA).

## How to Run
1. Open the project in NetBeans (Maven Java Application).
2. Go to `src/main/java/software/reuse/`.
3. Right-click any of Task1Main, Task2Main, Task3BrokenMain, Task3FixedMain, Task4Main and choose **Run File**.
